## Project Overview

This repository contains the practical work for the Advanced Database Management Systems Individual Practical Portfolio. The project focuses on the design, implementation, analysis, optimisation, and management of a logistics database system. The portfolio explores relational database design, SQL query optimisation, transaction processing, NoSQL modelling, and distributed database concepts.

## Portfolio Components

1. Database Design and Modelling
2. Query Processing and Optimisation
3. Transactions and Concurrency
4. NoSQL and Advanced Data Models
5. Distributed and Cloud Database Exercise

## Organisation

TrustSend25 is a fictional logistics and delivery company that connects customers, delivery hubs, and sweepers (dispatch). The database supports customer management, delivery requests, hub and sweeper assignments, delivery tracking, payment-related records, and operational reporting.
